# Ghost Server 0.2.0

Ghost Server 0.2.0 turns the initial SSH dashboard into an operational server-management application.

## Added

- Services workspace with refresh, start, stop and restart actions.
- Docker workspace with container discovery and start/stop/restart actions.
- Logs workspace with a bounded recent journal view.
- Strict service/container identifier validation before administrative commands are composed.
- Administrative service actions use non-interactive `sudo -n`; Ghost Server never pipes the session password into sudo.
- Windows release packaging now produces both:
  - `GhostServer-Portable.exe`
  - `GhostServer-Setup.exe`
- Inno Setup installer with Start menu registration, optional desktop shortcut and uninstall support.
- Release workflow that publishes the version only after the main Windows CI succeeds.

## Packaging gate

A release is rejected if either executable is missing or unexpectedly small. The same package construction runs in pull-request CI before merge.
