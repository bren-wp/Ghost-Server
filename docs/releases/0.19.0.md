# Ghost Server 0.19.0

Ghost Server 0.19.0 completes an accessibility and UI-performance pass across the Windows application.

## Keyboard focus and accessibility

- Added one Ghost focus visual used by buttons, text inputs, password inputs, combo boxes, check boxes and list rows.
- Keyboard focus is now visible instead of relying on platform-default focus chrome that could disappear against the dark theme.
- Add/Edit Server is a focus scope with cyclic Tab and Shift+Tab navigation.
- Delete confirmation is also a focus scope and initially focuses the safe Cancel action rather than the destructive action.
- Add/Edit Server labels are explicitly associated with their input controls.
- Add/Edit Server Save is the default Enter action; Cancel remains available through Escape.
- Closing a modal restores keyboard focus to the control that opened it when that control is still available.
- Successful save/delete moves focus to the server list so keyboard navigation continues from a valid visible surface.
- All 11 visible sidebar destinations have explicit AutomationProperties names, including compact icon-only mode.
- The compact Add server header action keeps an explicit accessible name even when its text label is hidden.
- Global application status and connection status are polite live regions.
- Server-editor validation errors are assertive live regions.

## Collection performance

- ListView and ListBox controls now explicitly use UI virtualization.
- Virtualization mode is Recycling so item containers are reused instead of recreated during large-list scrolling.
- Content scrolling and automatic vertical/horizontal scrollbars are standardized at theme level.
- Device-pixel snapping is enabled for virtualized collection surfaces.
- Existing Ghost custom scrollbars remain active for the virtualized views.

## Responsive rendering performance

- Responsive layout now has a compact breakpoint signature.
- Expensive page-margin, sidebar-column and navigation-column rewrites run only when a breakpoint state actually changes.
- Modal dimensions continue to track live window dimensions on every resize.
- Dashboard auto-refresh pauses while the window is minimized or not visible, avoiding unnecessary SSH polling in the background.

## UI quality

- Window layout rounding and pixel snapping remain enabled.
- Modal Tab navigation is trapped inside the active modal.
- Focus returns safely after Cancel/Close instead of falling onto a hidden overlay.
- The existing 0.18 sidebar alignment, custom Ghost scrollbar and dead-code gates remain enforced.

## Quality contract

- version and release-note consistency;
