# Ghost Server 0.11.0

Ghost Server 0.11.0 adds a dedicated read-only Database workspace and strengthens UI wiring validation in CI.

## Added

- Database workspace for PostgreSQL, MySQL/MariaDB and SQLite discovery.
- Engine version and service-state visibility.
- Read-only database-name discovery when the remote server already allows non-interactive local authentication.
- Clear access-state reporting when database listing requires credentials that Ghost Server does not have.
- Selected-engine database-name details without reading tables or row data.
- F5 refresh support for the Database workspace.
- CI audit that verifies XAML event handlers exist in the WPF code-behind before compilation.

## Security

- Ghost Server does not store database passwords.
- Database discovery never reads remote credential files.
- PostgreSQL and MySQL/MariaDB database listing uses only non-interactive local authentication that the server already permits.
- No CREATE, ALTER, DROP, INSERT, UPDATE, DELETE or other SQL mutation action is exposed in 0.11.0.
- SQLite discovery reports the installed client only and does not crawl the filesystem for database files.

## Delivery

Ghost Server 0.11.0 remains gated by version metadata, release notes, source hygiene, XAML event wiring audit, .NET analyzers with warnings as errors, Windows publish, installer verification, Portable launch smoke and Setup install/launch/uninstall smoke tests.
