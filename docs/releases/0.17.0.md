# Ghost Server 0.17.0

Ghost Server 0.17.0 completes a responsive Windows UI pass across the application and removes true full-screen/maximized behavior from the custom window chrome.

## Responsive window behavior

- Ghost Server always starts in a normal centered window.
- Initial width and height are calculated from the available Windows work area.
- Maximum window dimensions are capped below the full work area so the application never becomes a true full-screen window.
- The former Maximize action is now Fit window to screen and uses a bounded normal-window size.
- Double-clicking the custom title bar toggles Fit/comfortable window sizes instead of Windows Maximized state.
- External attempts to put the window into Maximized state are corrected back to the bounded Fit layout.
- The window remains freely resizable inside the supported minimum and maximum bounds.

## Responsive breakpoints

- The full 198 px navigation rail becomes a compact 72 px icon rail on narrower windows.
- Compact navigation retains tooltips for every visible destination.
- Section labels and the sidebar security footer collapse when space is constrained.
- Workspace header height, page title size, subtitle visibility and margins adapt to window width and height.
- The Add server header action becomes icon-only at the tightest width.
- Dashboard server-list width adapts so the detail area remains usable.
- Add-server and confirmation overlays resize to the available window instead of relying on fixed desktop dimensions.
- The status-bar shortcut legend hides before it can collide with operation status text.

## Workspace layout completion

- Fleet controls, selected-server probe controls, Alerts controls and Trends controls now wrap cleanly.
- Dashboard identity, edit/trust/delete actions and session-secret controls wrap instead of compressing into unusable columns.
- Files actions wrap and long status text no longer pushes controls outside the window.
- Network actions and firewall controls wrap across rows on narrow windows.
- Scheduled-task creation fields wrap while preserving full access to name, schedule, command and Create task.
- Security actions wrap cleanly.
- Settings monitoring and profile import/export controls adapt to narrow windows.
- Existing Services, Docker, System, Safe Update and other WrapPanel-based command bars remain responsive.

## UI completeness audit

- All 91 buttons in MainWindow have a Click or Command action.
- All 104 XAML event handlers resolve to a C# handler.
- No TODO, FIXME, placeholder, coming-soon or NotImplemented markers remain in the audited production UI and service source.
- No code path assigns WindowState.Maximized.
- Existing dark ComboBox, ListView, GridView, CheckBox and scrollbar styling from 0.16 remains intact.

## Security and operation behavior

This release does not weaken SSH host-key pinning, session-only secrets, mutation confirmation, operation-generation cancellation or release-provenance gates introduced in previous releases.

## Delivery

Ghost Server 0.17.0 remains gated by version consistency, release-note validation, source hygiene, XAML event-wiring validation, .NET analyzers with warnings as errors, self-contained Windows publish, Portable launch smoke test, Setup install/launch/uninstall smoke test and exact-artifact release provenance.
