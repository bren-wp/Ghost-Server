# Ghost Server 0.14.0

Ghost Server 0.14.0 adds local Fleet trend comparison and strengthens release provenance so the published Windows binaries are the exact artifacts that already passed main CI smoke tests.

## Added

- Dedicated Fleet Trends workspace.
- Compare the latest 10, 25 or 50 local Fleet probe records per server.
- Average and maximum CPU, RAM and disk utilization per server.
- Healthy, Attention and failed probe counts.
- Latest known local Fleet status.
- CSV export of the current trend comparison view.
- Fast jump from a trend row to the matching server on Dashboard.

## Release provenance

- Publish Release no longer rebuilds Ghost Server.
- The release workflow downloads the `GhostServer-windows-release` artifact from the successful validated main CI run that triggered it.
- The exact Portable and Setup binaries that passed the main CI launch/install smoke tests are the binaries published to GitHub Releases.
- SHA-256 checksums are generated from those validated binaries.
- Existing release tags are treated as immutable and are never overwritten by the workflow.

## Privacy

- Fleet Trends uses local Fleet health history only.
- Trend calculations and CSV export stay on the Windows machine running Ghost Server.
- No passwords, passphrases, private-key material, database credentials or remote command output are included.

## Delivery

Ghost Server 0.14.0 remains gated by version metadata, release-note validation, source hygiene, XAML event-wiring validation, .NET analyzers with warnings as errors, Windows self-contained publish, installer verification, Portable launch smoke and Setup install/launch/uninstall smoke tests.
