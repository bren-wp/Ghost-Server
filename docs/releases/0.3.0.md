# Ghost Server 0.3.0

Ghost Server 0.3.0 is the production-polish milestone focused on Windows UI quality, safer profile management, operational ergonomics and packaging reliability.

## Highlights

- Fluent icon system across navigation and primary actions.
- Branded Ghost Server application and installer icon.
- Clear active-navigation state, refined spacing, button hierarchy and status surfaces.
- Edit, delete and host-key reset workflows for server profiles.
- Session lock action that clears the in-memory password/passphrase.
- Improved service and Docker workflows with selected-item context and log shortcuts.
- Client-side log filtering and terminal command history.
- Keyboard shortcuts for common actions.
- Stronger empty/error states and safer destructive-action confirmation.
- Installer CI now performs silent install, launch and uninstall smoke validation.
- Portable and Setup executables remain mandatory release assets.

## Delivery

Every v0.3.0 release candidate must pass restore, build, publish, installer build, executable verification, portable launch smoke test and setup install/launch/uninstall smoke test before merge.
