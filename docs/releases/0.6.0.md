# Ghost Server 0.6.0

Ghost Server 0.6.0 adds the guarded Safe Update and configuration-restore workflow.

## Added

- Safe Update preview with host, kernel, root free space, reboot-required state, failed units and pending packages.
- Supported upgrade execution for APT, DNF, YUM, Zypper and pacman.
- Mandatory downloaded configuration snapshot before package mutation.
- Minimum 1 GiB root free-space gate.
- Required non-interactive sudo gate.
- APT `--force-confold` behavior to preserve existing configuration files.
- Post-update health verification.
- Explicit no-automatic-reboot policy.
- Configuration snapshot restore over verified SFTP.
- Restore path allowlist validation, traversal protection and rejection of links/special entries.
- Single-mutation serialization shared with service, Docker, firewall and backup operations.

## Cleanup

The superseded read-only update method was removed. The Updates workspace is now clearly labeled Safe Update so read-only preview and package mutation are not confused.

## Delivery

Both `GhostServer-Portable.exe` and `GhostServer-Setup.exe` remain mandatory. Release publication requires successful analyzer/compiler build, self-contained publish, installer build, executable verification, Portable launch smoke and Setup install/launch/uninstall smoke on `main`.
