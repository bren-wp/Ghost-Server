# Ghost Server 0.15.0

Ghost Server 0.15.0 replaces the Terminal workspace's command-per-request UX with a real persistent SSH ShellStream session while preserving the existing fail-closed host-key trust boundary.

## Added

- Persistent interactive SSH shell session for the selected server.
- Explicit Connect shell and Disconnect lifecycle controls.
- Streaming terminal output into the existing Ghost terminal surface.
- Commands are sent into the same shell so working directory, exported variables and other shell state persist between commands.
- One interactive shell session per Ghost Server UI session.
- Terminal output is bounded in memory to avoid unbounded UI growth.

## Lifecycle and safety

- The interactive shell uses the same pinned SHA-256 SSH host-key verification as all other SSH operations.
- Unknown or changed host keys remain blocked.
- Passwords and private-key passphrases remain session-only and are never persisted.
- Terminal connect is cancelled and the shell is disposed when the selected server changes.
- The shell is also disposed when SSH trust is reset, the active profile is edited or deleted, the session is locked, or the Ghost Server window closes.
- A server/profile transition cannot silently redirect an already-running shell to another server.
- Global Ctrl+N, Ctrl+L and F5 actions no longer run behind the add-server or confirmation overlays.

## Terminal UX

- Terminal status clearly reports Disconnected, Connecting, Connected, Trust required or Connection failed.
- Send is disabled until the persistent shell is connected to the currently selected profile.
- Quick Commands still insert text only and never execute automatically.
- Up/Down command history remains local to the application session.
- Clear removes terminal output locally and does not send a remote command.
- The v0.15 terminal is intentionally line-oriented; it does not claim full-screen terminal-emulator support for applications such as vim or top.
