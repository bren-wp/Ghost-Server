# Ghost Server 0.5.0

Ghost Server 0.5.0 is the stabilization and completion-polish milestone.

## Highlights

- Settings & About workspace with configurable monitoring interval.
- Optional default configuration-backup destination.
- Validated profile export/import without passwords or passphrases.
- Atomic JSON persistence with previous-state backup and malformed-primary recovery.
- Dynamic version badge sourced from assembly metadata.
- Bounded local crash diagnostics for unexpected runtime failures.
- Stateless SSH/SFTP client cleanup and shared authentication/connection construction.
- Serialized remote administrative mutations to prevent overlapping changes.
- Confirmation for disruptive service and Docker stop/restart operations.
- Responsive dashboard, Services and Docker action toolbars.
- Neutral server profile marker instead of a false always-online indicator.
- .NET analyzers enabled and warnings treated as errors.
- Current GitHub Actions majors using the Node 24 runtime.

## Dead-code and quality audit

The codebase was audited for private handlers that have no call/XAML reference and for unused XAML resource keys. No orphaned private handlers or unused resource keys remained. Analyzer findings were fixed rather than suppressed.

## Delivery

Release candidates must pass version consistency, restore, analyzer/compiler build, self-contained publish, installer build, executable verification, Portable launch smoke test and Setup install/launch/uninstall smoke test before merge and release publication.

Both `GhostServer-Portable.exe` and `GhostServer-Setup.exe` are mandatory release assets.
