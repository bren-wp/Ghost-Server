# Ghost Server 0.8.0

Ghost Server 0.8.0 completes another core operations area with a dedicated System workspace.

## Added

- System workspace with top process inventory.
- Read-only filesystem and mount overview.
- Read-only logged-in user/session overview.
- Explicit process termination action limited to the selected numeric PID.
- Confirmation before sending SIGTERM.
- F5 refresh support for the System workspace.
- Source-hygiene CI gate for TODO, FIXME and NotImplementedException leftovers.

## Safety

- Process discovery is read-only.
- Process termination only sends SIGTERM to the validated selected PID.
- Ghost Server does not send SIGKILL automatically.
- Storage and user/session data are read-only.
- All remote actions continue to require the pinned SSH host identity.

## Delivery

Both `GhostServer-Portable.exe` and `GhostServer-Setup.exe` remain mandatory. Release publication requires successful analyzer/compiler build, source-hygiene audit, self-contained publish, installer build, executable verification, Portable launch smoke and Setup install/launch/uninstall smoke on `main`.
