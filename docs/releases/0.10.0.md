# Ghost Server 0.10.0

Ghost Server 0.10.0 is a product-polish release focused on faster terminal workflows and a complete public-facing project presentation.

## Added

- Terminal Quick Commands for common read-only Linux inspection tasks.
- Presets for system summary, top processes, listening sockets, disk usage, Docker containers and recent journal errors.
- Presets are inserted into the command editor for review and are never executed automatically.
- Branded README hero artwork and secure-operations workflow artwork.
- Fully redesigned marketing README with release/download CTAs, feature matrix, security model, architecture, shortcuts and QA details.

## Improved

- README now clearly distinguishes read-only discovery from guarded administrative changes.
- Download links point to the current tagged release pattern for Portable and Setup builds.
- Security and Fleet positioning are easier to understand for new users and contributors.
- Product branding is visually aligned with the Ghost visual system used by the application.

## Delivery

Ghost Server 0.10.0 remains gated by version metadata validation, release-note validation, source-hygiene audit, .NET analyzers with warnings as errors, Windows self-contained publish, installer creation, Portable launch smoke and Setup install/launch/uninstall smoke tests.
