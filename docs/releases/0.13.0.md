# Ghost Server 0.13.0

Ghost Server 0.13.0 adds a local Alert Center on top of Fleet health history and introduces safe CSV export for operational review.

## Added

- Dedicated Alert Center workspace.
- Active, acknowledged and all-alert filters.
- Local acknowledgement for Attention and failed Fleet probe events.
- Alert counters for active, acknowledged, threshold-attention and probe-failure events.
- Fast jump from an alert to the matching server on Dashboard.
- CSV export of local alert history with server, timestamp, status, acknowledgement state, CPU, RAM, disk, load and reason.
- Stable local IDs for Fleet health records.

## Privacy and safety

- Alert Center uses only local Fleet health history.
- Acknowledging an alert never changes the remote server and never alters its current health state.
- CSV export contains no passwords, passphrases, private-key material, database credentials or remote command output.
- No alert data is uploaded or sent to a third-party service.
- Existing Fleet probe security boundaries remain unchanged.

## Delivery

Ghost Server 0.13.0 remains gated by version metadata, release-note validation, source hygiene, XAML event-wiring validation, .NET analyzers with warnings as errors, Windows self-contained publish, installer verification, Portable launch smoke and Setup install/launch/uninstall smoke tests.
