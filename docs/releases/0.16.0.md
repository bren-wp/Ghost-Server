# Ghost Server 0.16.0

Ghost Server 0.16.0 hardens remote-operation lifecycle safety across the application and cleans up the Windows UI so navigation, forms, tables and grouped workspaces follow one consistent dark Ghost design.

## Operation safety

- Selected-server remote operations now capture an immutable profile snapshot, session secret, operation generation and cancellation token before leaving the UI thread.
- Changing the selected server invalidates the previous operation generation and cancels selected-server remote work.
- Lock session, SSH trust reset, active-profile edit/delete and window shutdown cancel stale remote work in addition to closing the interactive terminal.
- Completed work is applied to the UI only when its operation generation still belongs to the currently selected server.
- Duplicate refreshes are gated per workspace without blocking unrelated read-only work.
- Operation gates are generation-aware so a delayed finally block from an old server cannot clear the busy state of a newer operation.
- CancellationTokenSource instances are retained until window disposal so in-flight code never depends on a disposed cancellation source.

## Workspaces covered

- Dashboard connection, service summary and auto-refresh.
- Files browse, upload and download.
- Services refresh, actions and service logs.
- Docker refresh, actions and container logs.
- Network discovery and firewall allow rule.
- Safe Update preview, update workflow, restore and configuration backup.
- Scheduled task refresh, create and delete.
- System refresh and process termination.
- Database discovery.
- Logs and read-only Security scan.

Maintenance cleanup intentionally targets the captured original server profile even after a UI switch, so temporary Safe Update, restore and backup files are never redirected to a newly selected server.

## Navigation and UI cleanup

- Sidebar width reduced and navigation rows made more compact.
- Every visible navigation row uses the same fixed icon column and aligned text baseline.
- Top-level navigation reduced from 17 visible items to 11.
- Alerts and Trends are grouped under Fleet.
- Backup and Tasks are grouped under Safe Update.
- Databases and Logs are grouped under System.
- F5 refresh is now based on the actually visible workspace, preserving correct refresh behavior for grouped child pages.
- Combo boxes use a custom dark popup and selection template instead of the default light Windows surface.
- ListView rows and GridView headers now use Ghost dark surfaces, hover and selected states.
- Check boxes and scrollbar surfaces are aligned with the dark theme.
- Related-workspace buttons are available directly from Fleet, Safe Update and System.

## Security boundaries

- Pinned SSH host-key verification is unchanged and remains fail-closed.
- Passwords and private-key passphrases remain session-only.
- No new background daemon, telemetry upload, bulk mutation or automatic reboot behavior is introduced.
- Existing single-mutation protection remains in place for administrative changes.
