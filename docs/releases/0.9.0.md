# Ghost Server 0.9.0

Ghost Server 0.9.0 adds a dedicated Fleet workspace for managing larger server collections without weakening the session-secret model.

## Added

- Fleet inventory for every saved server profile.
- Filterable fleet table with endpoint, authentication, SSH trust, last-connected and live-health fields.
- Parallel read-only health probes for trusted private-key profiles that can authenticate without a passphrase.
- Explicit selected-server health probe with a session-only secret.
- Fast jump from a Fleet row to that server on Dashboard.
- Fleet summary counters for saved, trusted, healthy and attention-needed profiles.
- Release checksum manifest generated from final Windows assets.
- CI gate requiring release notes for the current version.

## Security

- Fleet never persists passwords or private-key passphrases.
- Bulk health probes skip password profiles and untrusted SSH identities.
- A Fleet session secret applies only to the currently selected Fleet row.
- Health probes are read-only and use the same pinned SSH host-key verification as the rest of Ghost Server.

## Delivery

The release remains gated by version validation, source-hygiene audit, .NET analyzers, build, self-contained publish, installer construction, executable verification, Portable launch smoke and Setup install/launch/uninstall smoke.
