# Ghost Server 0.7.0

Ghost Server 0.7.0 adds isolated scheduled operations for Linux servers.

## Added

- Tasks workspace with Ghost Server systemd timer inventory.
- Read-only visibility into the connected user's crontab.
- Hourly, Daily and Weekly timer creation.
- Validated task names with the dedicated `ghost-server-*` namespace.
- Base64 task-script transfer to avoid command interpolation during file creation.
- Root-owned task scripts under `/usr/local/lib/ghost-server/tasks`.
- Explicit confirmation before create/delete mutations.
- Delete workflow limited to the selected Ghost Server timer, service and script.
- F5 refresh support for the Tasks workspace.

## Safety

Ghost Server does not edit the user's crontab and does not touch unrelated systemd timers. Scheduled commands are entered explicitly by the administrator and run through a dedicated oneshot service.

## Delivery

Both `GhostServer-Portable.exe` and `GhostServer-Setup.exe` remain mandatory. The release is published only after successful analyzer/compiler build, self-contained publish, installer build, executable verification, Portable launch smoke and Setup install/launch/uninstall smoke on `main`.
