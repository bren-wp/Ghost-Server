# Ghost Server 0.4.0

Ghost Server 0.4.0 expands the application from server control into day-to-day operations.

## Added

- Network workspace with interfaces, routes, listening sockets and firewall state.
- Safe firewall allow-rule workflow for validated TCP/UDP ports.
- Updates workspace with distribution-aware, read-only package update discovery.
- Backup workspace that creates a remote configuration snapshot, downloads it over pinned-host SFTP, then removes the temporary remote archive.
- Dashboard auto-refresh option for live server monitoring.
- Scrollable navigation rail to keep all workspaces usable on smaller supported window heights.
- Operational actions continue to use verified SSH host identity and non-interactive sudo.

## Safety

- Firewall input is strictly validated to port 1-65535 and TCP/UDP only.
- Ghost Server never automatically removes firewall rules or disables a firewall.
- Update discovery is read-only in this milestone.
- Configuration snapshots use a fixed allowlist of server configuration directories.
- Temporary remote backup archives are deleted after a successful or failed download attempt.

## Delivery

Portable and Setup executables remain mandatory. Pull-request and main CI must pass build, self-contained publish, installer construction, executable verification, portable launch smoke and Setup install/launch/uninstall smoke before release publication.
